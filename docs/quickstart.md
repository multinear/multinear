# Multinear: Quick Start Guide

Multinear helps you quickly establish clear pass/fail benchmarks and automatically detect regressions. Follow these quickstart steps to define actionable evaluations aligned to your real-world business outcomes, run structured experiments, and gain visibility to rapidly iterate your GenAI solution reliably.

## 1. Install Multinear

Install Multinear from PyPI:

```bash
pip install multinear

# we recommend using `uv`
# uv add multinear
```

## 2. Initialize Your Project

Create a Multinear project structure in your existing project directory:

```bash
multinear init
```

You'll be prompted to enter:

- **Project Name**.
- **Project ID**: A URL-friendly identifier (auto-generated by default).
- **Project Description**: Brief summary of your project's purpose.

This command creates a `.multinear` folder containing configuration files and an SQLite database to store experiment results. Commit this folder alongside your code for easy version tracking.

## 3. Define a Task Runner

Create `.multinear/task_runner.py` to integrate Multinear directly with your AI application logic.

Example `task_runner.py`:

```python
def run_task(input):
    # Directly call your AI logic here
    # If external, use API calls (e.g., via `requests`)
    output = my_application.process(input)
    details = {'model': 'gpt-5'}
    return {'output': output, 'details': details}
```

Task runner hooks:

* **Optional** `start_run()`: Called once before tasks start; useful for initialization.
* **Required** `run_task(input)`: Process each task input, returning output and details.
* **Logs capture**: All console logs from your code are captured and visible for debugging.

## 4. Configure Meaningful Evaluations

Define clear, binary evaluations tied directly to your business outcomes in `.multinear/config.yaml`.

**Example**:

```yaml
project:
  id: bank-customer-support
  name: Acme customer support
  description: Testing customer support using FAQ and manuals

tasks:
  - id: activate-credit-card-no-pin
    input: I received my credit card today but there's no PIN with it. What should I do to start using it?
    checklist:
      - Answer outlines the process for activating a credit card without an existing PIN.
      - Answer mentions logging into Online Banking or the mobile app to access the 'Cards' section.
      - Answer includes steps to set a new PIN and the option to activate the card by opting to sign for payments initially.
      - Answer provides alternatives such as visiting a branch or contacting support if online methods are unavailable.
    min_score: 0.8  # Use 1.0 for strictly defined binary criteria
```

## 5. Run Your Experiments and Detect Regressions

Set up OpenAI credentials to enable LLM‑based evaluators (Checklist, Weighted Score, and Numeric when using LLM extraction) and input rephrasing.

```bash
export OPENAI_API_KEY=sk-...
```

Start the Multinear web platform:

```bash
multinear web
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser.

![Experiment Overview](/static/experiment.png)

**Regression Detection:**

Multinear reveals regressions from any change — comparing each run to your baseline automatically. If your latest change broke something previously working, you'll know immediately.

### Prefer CLI? Use:

```bash
multinear run
```

You’ll see results like:

```sh
Running experiment...
✅ Task 'Test1': PASSED
Experiment finished: 1/1 tasks passed 🎉
```

## 6. Analyze Results with Actionable Insights

Multinear captures detailed logs and rationales, clearly showing why tests fail—prompt wording, data issues, or unexpected model behavior. Use this visibility to quickly pinpoint issues, rapidly iterate, and confidently improve your AI application.

- **Run Summaries**: Overview of pass/fail status and overall scores.
- **Detailed Reports**: Inputs, outputs, logs, and evaluation details.
- **Trend Analysis**: Compare runs to detect regressions or improvements.
- **Filtering and Search**: Easily navigate large evaluation sets.
